# Components

This project uses the following hardware components:

| Component | Description |
|---|---|
| Arduino Mega 2560 | Main microcontroller used to control the feeder |
| 20x2 LCD display | Displays menu options, status and configuration values |
| 4x4 matrix keypad | Allows menu navigation and numeric input |
| Servo motor | Controls the food dispensing mechanism |
| Buzzer | Provides sound feedback for clicks, confirmation and feeding action |
| Jumper wires | Used for electrical connections between modules |
| Power supply | Provides power to the Arduino and connected components |
| Mechanical food container | Stores and dispenses pet food |

## Planned Hardware Improvements

In the future, the Arduino Mega 2560 may be replaced with an ESP32 microcontroller to add Wi-Fi connectivity, remote control and integration with a mobile application.
